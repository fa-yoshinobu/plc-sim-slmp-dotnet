# 機能一覧

PLC Sim（SLMP）に実装済みの機能です。使い方は [README](../README.md)、開発者向けの情報は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

「実機確認済み」は、実機 iQ-R 系（R08PCPU）に同じ要求を送り、応答が一致することを確かめた項目です。

## 通信

- 3E / 4E フレーム × バイナリ / ASCII。受信した伝文に合わせて同じ形式で応答し、4E はシリアル番号を折り返します。
- TCP（複数接続を同時に受付）と UDP を同時に待ち受けます。
- 交信データコードの設定（`server.dataCode`）
  - 自動：バイナリと ASCII の両方に応答します。
  - バイナリ / ASCII：設定と違うコードの要求には応答しません（実機確認済み）。応答しなかった要求は通信ログに「無応答」と残ります。
- 待受アドレス・ポートを設定できます。既定は `127.0.0.1:1025` で、`0.0.0.0` にすると他の PC から接続できます。

## コマンド

`PlcComm.Slmp`（plc-comm-slmp-dotnet）が使う 26 コマンドに対応します。それ以外のコマンドには C059 を返します。

| 分類 | コマンド |
|---|---|
| デバイス | 一括読書き（0401 / 1401）、ランダム読書き（0403 / 1402）、ブロック読書き（0406 / 1406）、モニタ登録・実行（0801 / 0802） |
| ラベル | 配列ラベル読書き（041A / 141A）、ランダムラベル読書き（041C / 141B） |
| メモリ | 自局メモリ読書き（0613 / 1613）、拡張ユニット読書き（0601 / 1601） |
| リモート操作 | RUN / STOP / PAUSE / ラッチクリア / リセット（1001〜1006）、パスワード解除・ロック（1630 / 1631） |
| 保守 | 形名読出し（0101）、折返し（0619）、エラー初期化（1617） |

- サブコマンド 0000〜0003（Q/L 形式・iQ-R 形式、ワード / ビット単位）と、拡張指定 0080〜0083（Un\G、U3E0〜U3E3\G・\HG、Jn\X/Y/B/SB/W/SW、Z / LZ インデックス修飾）に対応します。拡張指定とラベルはバイナリのみです。
- ビット単位の一括読書きの上限は、バイナリが機種の上限（iQ-R・Q・L は 7168 点）、ASCII が 3584 点です。
- 複数の対象への書込み（ランダム・一括・ブロック・配列ラベル・拡張ユニット・リンクダイレクト）は、書く前に全件を確かめ、1 件でも誤りがあれば何も書きません。
- 1 回の応答に収まらない読出し（大きなラベルなど）は、応答を組み立てる前にエラー応答（C05C）で断ります。上限はデータ長欄（16 ビット）と、UDP では 1 データグラム（IPv4、ヘッダ込み 65,507 バイト）です。
- 不正な要求で PLC Sim の内部エラーが起きても、その要求に応答しないだけで、待受は続けます（通信ログに残ります）。

## 実機に合わせた応答（実機確認済み）

実機 iQ-R 系（R08PCPU）に同じ要求を送り、応答をバイト単位で比べて合わせています（バイナリ 70 項目以上、ASCII 63 項目以上）。

| 状況 | バイナリ | ASCII |
|---|---|---|
| データ長の過不足 | C061 | C058 |
| 16 進・10 進でない文字 | — | C050 |
| ビット書込みの値が 0 / 1 以外 | C060 | C050 |
| 未定義のサブコマンド | C05C（データ長より先に確認） | C05C（データ長のあとに確認） |
| ランダム読出し・モニタ登録のビット単位指定 | C061 | C05B |
| ブロック読書きのビット単位指定 | C0D9 | C0D9 |
| 未知のデバイスコード | C05B | C05B |
| デバイス範囲外（パラメータ点数を超える番地、最終番地をまたぐ範囲） | 4031 | 4031 |
| 拡張指定で未装着のユニット（Un\G）・未登録のネットワーク（Jn\） | 4031 | — |
| 拡張ユニット読書き（0601 / 1601）で未装着のユニット | 4043 | 4043 |
| 読出し専用デバイス（S）への書込み、LTC / LTS の一括読書き | 4030 | 4030 |
| LTC / LTS のワード・ダブルワード単位のランダム読書き、LTC / LTS を登録したモニタの実行 | 4032 | 4032 |
| LTN / LSTN の一括書込みが 4 ワード単位でない | C051 | C051 |
| iQ-R 系で、インデックス修飾を Q/L 形式（0080 / 0081）で指定 | C05A | — |
| ラベルなし | 40C5 | — |
| リモート操作のモード不正 | 400B | 400B |
| リモートリセットがパラメータで不許可 | 408B | 408B |
| モニタ実行の不正なサブコマンド | 4002（エラー情報のコマンドは 0403） | 同じ |

そのほかの動き：

- iQ-R 系では、モニタ実行（0802）のサブコマンド 0002 も受け付けます。インデックス修飾は iQ-R 形式（0082 / 0083）なら Z・LZ とも受け付けます。
- モニタ登録は接続をまたいで残ります（別の接続の 0802 でも、登録したデバイスを返します）。
- LTN / LSTN の一括読出しはワード単位で読め、一括書込みは 4 ワード（1 点分の構造）単位で受け付けます。LTC / LTS のランダムビット書込みは受け付けます。
- 書込みで 1 件でも範囲外があれば何も書かない動き（ランダム・一括・ブロック）は、実機と同じです。
- 形名読出しと折返しはサブコマンドを確認しません。
- ランダムビット書込みの値は、0 以外をすべて ON として扱います。
- リモートパスワードを設定していないとき、解除・ロックの要求には正常終了を返します（ロックはされません）。
- リモートリセット：RUN 中・PAUSE 中は 4013 を返します。STOP 中は応答を返さずに全接続を切って再起動し、再起動後は「起動時の状態」になります。再起動中に応答しない時間は `plc.resetRestartMs` で指定できます（実機は約 22 秒、既定 0）。
- 交信データコードをバイナリ / ASCII に設定すると、違うコードの要求には応答しません（実機と同じ）。
- 終了コードの根拠は `src/PlcSim.Slmp.Core/Protocol/EndCodes.cs` に区分（実機計測 / マニュアル / 参考実装 / 未検証）で記載しています。Q / L / iQ-F の機種にも、iQ-R 系で計測した値を使っています。

## 機種

| 機種 | 接続先 |
|---|---|
| `melsec:iq-r`（既定）、`melsec:iq-r:rj71en71` | iQ-R CPU 内蔵 Ethernet、RJ71EN71 |
| `melsec:qnudv`、`melsec:qnu` | Q CPU 内蔵 Ethernet |
| `melsec:qcpu:qj71e71-100`、`melsec:qnu:qj71e71-100`、`melsec:qnudv:qj71e71-100` | Q + QJ71E71-100 |
| `melsec:lcpu`、`melsec:lcpu:lj71e71-100` | L CPU 内蔵 Ethernet、L + LJ71E71-100 |
| `melsec:iq-f` | iQ-F（FX5U など） |

- 機能の可否と点数上限は、plc-comm-slmp-dotnet の実機計測値に合わせています（例：Q 内蔵 Ethernet は形名読出し・ブロック読書き・Un\G・Jn\ が C059、iQ-F は X/Y が 8 進でモニタ非対応）。
- 形名・形名コードは設定で変更できます。L の形名コードは未確認のため 0 を返します。

## 仮想 PLC のメモリ

- iQ-R の既定の点数は、実機の最大デバイス試験と同じです（M/D/T/C/LT 262144 点、B/W 40000h、ZR 4915200 点、RD 1048576 点など）。
- 実機と同じメモリの共有：DX/DY = X/Y、R = ZR の先頭（最大 32768 点）、LTC/LTS = LTN 状態ワードの bit0/bit1。
- LTN/LSTN は 1 点 4 ワード、LCN/LZ は 1 点 2 ワードの構造です。S は読出し専用です。
- 特殊レジスタ：SD260〜（Q/L は SD286〜）にデバイス点数、SD203 に CPU 状態（RUN/STOP/PAUSE）、SD0 に自己診断エラー、SD210〜216 に時計を反映します。
- デバイス点数は、実機のパラメータに合わせて変更できます（GUI の「デバイス範囲」、設定の `plc.devicePoints`）。
- バッファメモリ（Un\G）の装着ユニットと、リンクダイレクト（Jn\）のネットワーク番号を各最大 4 個登録できます（既定は U0 と J1）。CPU バッファメモリ U3E0〜U3E3 は登録不要です。
- ラベル：既定は `SLMP_TEST`（WordValue: WORD、WordArray: WORD[2]）。グローバルラベルと構造体を追加・編集・削除できます。定義は名前の形式・重複、未定義の型、構造体の循環参照、配列要素数、サイズを確認します。
- RUN 中の書込み許可、リモートリセット許可、リモートパスワード、起動時の状態を設定できます。
- メモリ全体のスナップショット保存・復元ができます。

## 試験用の機能

- エラー注入：コマンドごとに、任意の終了コード、応答の遅延、無応答を指定できます。
- 通信ログ：要求・応答の伝文と、項目ごとの分解表示。
- 直近アクセス：読出し・書込み、アクセス元、回数を記録します（連続する同じアクセスはまとめます）。

## GUI（Windows）

| 画面 | 内容 |
|---|---|
| ダッシュボード | CPU の状態、接続中のクライアント、要求数の推移、RUN / STOP / PAUSE / リセット、サーバーの起動・停止 |
| メモリビューア | 全デバイス・バッファメモリ・リンクダイレクト・ラベルの表示と編集。番地ジャンプ、表示形式の切替、値のある番地だけ表示、書込みのハイライト、範囲バー、CSV 出力、直近アクセスの一覧 |
| 通信ログ | 伝文の一覧と分解表示 |
| スクリプト | Python スクリプトの作成・編集・実行・停止 |
| デバイス範囲 | デバイス点数、装着ユニット、ネットワーク番号の設定 |
| ラベル | グローバルラベルと構造体の定義 |
| 設定 | 機種、形名、待受、交信データコード、動作条件、HTTP API、Python、表示テーマ、エラー注入 |
| バージョン情報 | バージョン、使用ライブラリ、ライセンス |

- 画面デザインはデジタル庁デザインシステム（DADS）に合わせています。表示テーマはシステム / ライト / ダークから選べます。
- 起動引数：`--config`、`--theme`、`--page`、`--address`。

## Python スクリプト・HTTP API

- Python ライブラリ `python/plc_sim.py`（標準ライブラリのみ）：値の読書き、周期処理（`@plc.every`）、書込みへの反応（`@plc.on_write`）、CPU 状態変化への反応（`@plc.on_state`）、エラー注入。
- 起動時にスクリプトを自動実行できます（設定の `scripts`）。
- HTTP 制御 API（`http://127.0.0.1:5080`）：デバイス・ラベルの読書き、加算・反転、CPU 状態の変更、エラー注入、通信ログ、スナップショット、スクリプト一覧、書込み・状態変化の通知（Server-Sent Events）。

## コンソール版

- 画面なしで動かせます。起動引数：`--config`、`--profile`、`--port`、`--api-port`、`--snapshot`、`--verbose`。
- 対話コマンド：`status`、`dump`、`set`、`run` / `stop` / `pause`、`labels`、`log`、`access`、`scripts`、`error`、`save` / `load`。

## 配布

- GUI・コンソールとも、.NET ランタイム同梱の 1 ファイル exe で配布します。
- 配布 zip には exe、`config/`、`python/`、`scripts/` が入り、展開するだけで Python スクリプトも使えます。
